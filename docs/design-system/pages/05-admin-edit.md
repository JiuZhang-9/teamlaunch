# 页面设计提示词 · 管理员编辑态（V-05）

> 触发：设置 → 管理员模式 → 口令验证通过｜写操作：`PUT /api/v1/config`（Bearer + HMAC）
> 核心要求：**管理员必须随时明确知道"我正在改团队页，还没发布"**（4 重信号，缺一不可）
> 完整信号规格见 `../components/edit-mode-signals.md`

## 4. 真实中文文案

**徽标**：`编辑模式`

**工具栏按钮**：`撤销` / `新建分组` / `新建入口`

**EditActionBar**
- 无改动：`当前版本 v26`
- 有改动：`已编辑 3 项，尚未发布`
- 按钮：`放弃改动` / `发布 · 3 项改动`（无改动时禁用的按钮文案为 `发布`）

**退出编辑确认**：`放弃未发布的改动？` / `有 3 项编辑尚未发布。放弃后团队页仍显示当前版本 v26，本机草稿会被清空。` / `继续编辑` / `放弃改动`

**Toast**
- 发布成功：`已发布 v27，3 项变更`
- 退出编辑：`已退出编辑模式，未发布的改动仍保存在本机`
- 签名失败：`签名校验未通过，请重新启用管理员模式`

**口令对话框**：`启用管理员模式` / `口令由管理员设置，输入后本机会获得团队页编辑权限` / `口令不正确，请重新输入` / `取消` / `启用`

**容量上限**：`团队页已接近整理上限（8 组 / 200 项），建议先合并相似分组`

**禁用词（本行为清单原文，扫描豁免）**：同全局清单；管理端另禁止 `一键部署` `推送到云端` `全员强制更新`

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| `Ctrl+Shift+E` | 进入 / 请求退出编辑模式 |
| `Ctrl+N` | 新建入口（插入当前分组末尾并聚焦名称输入） |
| `Ctrl+Shift+N` | 新建分组 |
| `Ctrl+Z` | 撤销上一次编辑（**只撤销一步**，不做多级历史） |
| `Alt+↑ / Alt+↓` | 卡片在组内移动顺序 |
| `Alt+Shift+↑ / ↓` | 分组整体移动顺序 |
| `F2` | 重命名当前卡片 |
| `Delete` | 删除当前卡片（确认对话框，默认焦点「取消」） |
| `Ctrl+Enter` | 打开发布对话框（等价点「发布 · N 项改动」） |
| `Esc` | 焦点在卡片：交回搜索框；焦点在输入框：取消就地编辑 |
| `Tab` | 工具栏 → 卡片网格 → EditActionBar（EditActionBar 是最后一个 tab stop） |

- 撤销后播报 `aria-live="assertive"`：`已撤销：修改「2026 年度归档」`
- 发布按钮 disabled 时必须带 `aria-disabled="true"` 且保留在 tab 序列中（不能 `disabled` 到无法聚焦，否则键盘用户不知道为什么按不动）

## 7. 实现红线（本页最容易做错）

1. **编辑态 4 重信号必须全做**。只加一个"编辑模式"徽标，管理员在滚动到页面中段、看不到工具栏和底栏时，会完全不知道自己在编辑态。
2. **发布按钮 disabled 时仍要可聚焦**并带 `aria-disabled`。直接 `disabled` 会让键盘用户按 Tab 跳过，永远不知道为什么发布不了。
3. **校验失败必须保留其他编辑**（AC-07）。把整个草稿清空再让管理员重填，是最伤人的实现。
4. **发布中不清空草稿**。只有服务端返回 200 才清；失败时草稿必须原样还在（否则一次网络抖动等于丢掉十分钟编辑）。
5. **隐藏编辑入口不是安全边界**（AC-16）。签名的校验在服务端，UI 隐藏只是易用性。
6. **`icon.kind=local` 的软件图标不跨网同步**（K-08）。管理员本机提取的 exe 图标对没装该软件的员工无意义，还会放大流量。员工端各自本地提取，提取不到用 `AppWindow` 回退。
7. **Windows 上 `app.getFileIcon({size:'large'})` 上限就是 32×32**（`SHGetFileInfo` 限制）。不要去找"高清提取方案"；图标槽 40px、实际图标 32px，小于 24px 时不要放大，直接回退 Lucide。
8. **分组超过 8 组不做折叠/分页/标签页**（C-03 已裁定），内容区纵向滚动即可。
