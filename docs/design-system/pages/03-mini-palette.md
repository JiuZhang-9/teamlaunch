# 页面设计提示词 · 迷你唤起面板（V-03）

> 触发：全局热键 `Ctrl+Space`（默认，可改）｜数据源：**本机内存索引**（团队缓存 + 个人入口合并）
> 性能硬指标：从按键到面板可见 **≤80ms**；输入到首批结果 **≤300ms**（AC-04）

---

## 1. 布局结构（具体尺寸）

面板是独立 `BrowserWindow`，无边框、无阴影外的标题栏，`--palette-w: 560`，高度自适应（内容 402，上限 420）。

```
┌──────────────────────────────────────────────────────────┐ 560
│ padding 8                                                │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ [Search 20]  搜索入口、分组或路径              [X 16] │ │ h=40
│ └──────────────────────────────────────────────────────┘ │
│ ───────────────────────────────────────────────────────  │ 1px
│ ┌ ResultRow ───────────────────────────────────────────┐ │
│ │ [icon16] 2026 年度归档   D:\共享\2026 归档   团队 Alt+1│ │ h=44
│ │ [icon16] 费用报销系统    expense.internal…   团队 Alt+2│ │
│ │ …（最多 7 行，含剪贴板候选行；超出用覆盖式滚动条）      │ │
│ └──────────────────────────────────────────────────────┘ │
│ ───────────────────────────────────────────────────────  │ 1px
│ ↑↓ / Tab 选择   ⏎ 打开   Ctrl+⏎ 加入口   Esc 关闭   │
└──────────────────────────────────────────────────────────┘
高度 = 8 + 40 + 1 + 7×44 + 1 + 36 + 8 = 402
```

| 元素 | 尺寸 | Token |
|---|---|---|
| 面板 | w 560，h auto（≤420），圆角 16 | `--palette-w` `--palette-h` `--radius-xl` |
| 面板外边距 | p 8 | `--space-2` |
| SearchInput | h 40，字号 15，图标 20，圆角 8 | `--control-h-lg` `--text-md` `--icon-20` |
| 分隔线 | 1px，左右不留白（通栏） | `--border-subtle` |
| ResultRow | h 44，p-x 12，gap 12 | `--row-h` `--space-3` |
| 行内类型图标槽 | 24 × 24（图标 16） | `--icon-16` |
| 行标题 | 14 / 510，单行截断 | `--text-base` `--weight-emphasize` |
| 行副标签 | 12 / 400，`--muted`，单行截断 | `--text-xs` |
| SourceTag | 12 / 400，圆角 6，p-x 6 | `--tag-bg` `--tag-fg` |
| Alt+n 提示 | 11 / 400，等宽，`--meta` | `--text-2xs` `--font-mono` |
| 底部快捷键栏 | h 36，p-x 12，字号 11 | `--text-2xs` |

**定位**：水平居中于当前显示器工作区；垂直位于工作区顶部下方 **18%**（`y = workArea.y + workArea.height * 0.18`）。不用居中——居中会盖住用户正在看的窗口内容。

## 2. 组件组合（Spec §7 组件名）

```
MiniPalette（独立 BrowserWindow）
├─ SearchInput      [Search 20] + 清空按钮 [X 16]（有输入时才出现）
├─ Divider
├─ ResultRow ×≤7    [Icon 16][标题][副标签][Spacer][SourceTag][Alt+n]
│    └─ 剪贴板候选行（唤起时读一次剪贴板；只认单条）[SourceTag=剪贴板][加为入口 Plus 按钮]
└─ 快捷键栏          [ChevronUp 16][ChevronDown 16] 选择 · Tab 切换 · ⏎ 打开 · Ctrl+⏎ 加入口 · Alt+1…7 直开 · Esc 收起
```

- 结果排序：名称前缀匹配 > 关键词匹配 > 分组名匹配 > 路径末级/域名匹配；同分时团队页优先，再按最近打开时间
- **每条结果必须同时有类型图标与类型文字**（AC-03）：图标在左，SourceTag 右侧写 `团队`/`本机`，屏幕阅读器 label 追加类型

## 3. 需要实现的全部状态

| # | 状态 | 触发 | 呈现 |
|---|---|---|---|
| S1 | Hidden（预热） | 应用启动后 | 隐藏的 BrowserWindow 已加载完毕，`show()` 前不绘制；**不允许冷启动创建**（K-09 同类） |
| S2 | Appearing | `Ctrl+Space` | `show()` + 输入为空；无淡入动画（80ms 预算里放不下动画），只做 `focus` |
| S3 | 空查询（最近打开） | 输入为空 | 列表顶部一行 11px 分组标签 `最近打开`，下列真实最近打开（最多 7 行）；**没有最近记录时回退显示清单前几条，且不显示该标签**（标签必须如实描述这批结果） |
| S3b | 剪贴板候选行 | 唤起时剪贴板里是**单条**网址/已存在的路径 | 置顶一行：`SourceTag=剪贴板`；内容是新的 → 行尾 `Plus` 按钮（`title` 为「加为入口（Ctrl+回车）」）；**已是清单里的一条 → 只置顶该条**（不重复插行）。含换行 / 超长 / 识别不出 → 不显示这一行 |
| S4 | Typing | 有输入 | 输入防抖 **120ms**；防抖期内保留上一次结果，不闪空 |
| S5 | Results | 匹配 ≥1 | ResultRow 列表，第 1 条默认 selected（`aria-selected="true"`） |
| S6 | Empty | 匹配 0 | 行内 EmptyBlock（h 132 居中）：`Search` 24 + `没有找到「报价」相关的入口` + `换个词试试，或到我的入口里添加` |
| S7 | Row Selected | `↑↓` | 背景 `--row-bg-selected` + 左侧 2px `--row-indicator` 竖条（**不要整行描边**） |
| S8 | Opening | `Enter` | 立即关闭面板并执行打开；**面板关闭不等待打开结果** |
| S9 | Closing | `Esc` / 失焦 | `hide()` 而非 `close()`，保留预热窗口；清空输入 |
| S10 | Hotkey 冲突 | 注册失败 | **不在本面板提示**——主窗口首启时 Banner 提示（见 §4），并把面板热键置为未注册 |
| S11 | 无结果且从未同步 | 团队数据为空 | 结果只来自个人入口；底部追加一行 11px `--meta`：`团队入口还没有同步，当前只显示我的入口` |
| S12 | 空清单（没有可打开的入口） | 团队 + 我的入口都没有内容 | **不显示结果列表**，行内 EmptyBlock（`LayoutGrid` 24）：`还没有可打开的入口` + `在「我的入口」里添加软件、文件夹或网页；复制的网址或路径在这里也能直接打开。` |

## 4. 真实中文文案

**SearchInput placeholder**：`搜索入口、分组或路径`

**底部快捷键栏**：`↑↓ 选择　Tab 切换　⏎ 打开　Ctrl+⏎ 加入口　Alt+1…7 直开　Esc 收起`

**空结果**：`没有找到「报价」相关的入口` / `换个词试试，或到我的入口里添加`

**空清单（S12）**：`还没有可打开的入口` / `在「我的入口」里添加软件、文件夹或网页；复制的网址或路径在这里也能直接打开。`

**剪贴板候选行**：标签 `剪贴板`；行尾按钮 `title` = `加为入口（Ctrl+回车）`，`aria-label` = `加为入口`

**分组标签**：`最近打开`（11px，`--muted`，只在空查询时出现）

**SourceTag**：`团队` / `本机`

**热键冲突（主窗口 Banner，非本面板）**
- 第 1 行：`全局热键 Ctrl+Space 没能注册`
- 第 2 行：`此热键可能已被输入法占用，建议改为 Ctrl+Alt+Space。`
- 动作：`去设置修改`（点击直达设置面板热键项）
- 约束：**不得反复弹窗、不得静默抢占**（AC-05）；本次会话内只提示一次

**禁用词**：同全局；面板内禁止出现任何网络请求相关字样（本视图 100% 本地）

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| `Ctrl+Space` | 唤起上次收起的窗口（主窗口或本面板）；已在最前时收起（同一个键开关，2026-10-21） |
| `Ctrl+Tab` | 与主窗口互换：面板里按回主窗口；主窗口里按则打开面板（托盘开启时主窗口进托盘） |
| `↑` / `↓` | 上下移动选中项，**循环**（到底部再按 ↓ 回到第一条） |
| `Enter` | 打开选中项并关闭面板；剪贴板候选行的回车也是**直接打开**，绝不弹任何窗口 |
| `Ctrl+Enter` | 剪贴板候选行（内容是新的）→ 加为入口：交给主窗口打开预填编辑器（面板窗口装不下编辑器） |
| `Alt+1` … `Alt+7` | 直接打开第 n 条（不移动选中态） |
| `Esc` | 关闭面板并清空输入 |
| `Tab` / `Shift+Tab` | 下一条 / 上一条（与 ↑↓ 同一个**循环**游标）。仍 `preventDefault`——焦点必须留在输入框，丢出去面板就会失焦隐藏；Tab 因此不再"禁用"，而是被复用为选择键 |
| 输入任意可打印字符 | 聚焦输入框（面板失焦于输入框时自动回填） |

- 面板内 `aria-live="polite"` 播报结果条数变化：`找到 7 个入口`
- 选中项通过 `aria-activedescendant` 关联，不移动 DOM 焦点
- 结果行 `aria-label`：`2026 年度归档，文件夹，团队入口，第 1 条，Alt+1 打开`

## 7. 实现红线（本页最容易做错）

1. **必须预热隐藏窗口**。冷启动 `new BrowserWindow()` + 加载 React 必超 80ms，`Ctrl+Space` 会明显卡顿。正确做法：应用启动即创建并 `hide()`，热键只做 `show()` + `focus()`。
2. **面板用 `hide()` 不是 `close()`**。关掉再开等于每次冷启动，第一次能用、第二次就慢。
3. **防抖 120ms，且防抖期内保留上一次结果**。清空重画会造成"输入时列表闪一下白"。
4. **Enter 后立刻关闭面板**，不要等 `shell.openPath` 的返回。等返回会让面板卡在屏幕上几百毫秒。
5. **`Alt+数字` 在 Windows 上会触发菜单栏**。必须在 `webContents` 层面拦截，不能只依赖 `preventDefault`。
6. **热键冲突不要在本面板弹窗**（AC-05 明确禁止反复弹窗）。冲突信息走主窗口 Banner + 设置页。
7. **本视图 100% 本地**，不得发起任何网络请求。出现"正在同步"字样即为实现错误。
