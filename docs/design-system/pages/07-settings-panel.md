# 页面设计提示词 · 设置面板（V-07）

> 触发：工具栏 `Settings` 按钮 / 托盘菜单「设置」/ 热键冲突 Banner「去设置修改」
> 硬性可达性：**遥测开关必须在一级可见位置，不折叠、不进子页**（PRD §15.3；5–8 人团队里每个人都要能找到）

---

## 4. 真实中文文案

**标题**：`设置`

**遥测（第 1 项）**
- 项名：`使用数据统计`
- 开：`正在记录匿名使用数据` + `已停止记录并清空本机待发送数据`（关闭时出现）
- 关：`关闭后不再记录任何使用数据`
- 未确认：`尚未确认隐私说明，暂不记录任何数据` + 按钮 `查看隐私说明`

**外观**：`浅色` / `深色` / `跟随系统`

**其他项名**：`开机自动启动` / `关闭主窗口时最小化到托盘`

**热键**：`全局唤起热键` / 按钮 `重新录制` / 录制态 `按下新的热键…` / 冲突 `此热键可能已被输入法占用，建议改为 Ctrl+Alt+Space` / 未设置 `未设置`

**缩放**：`界面缩放` / `80%` `100%` `125%` `150%`

**口令**：`管理员模式口令` / `设置口令` / `修改口令` / `口令由管理员设置，输入后本机会获得团队页编辑权限` / `口令没能保存到本机，请检查磁盘权限后重试`

**关于**：`关于` / `版本 1.0.0（团队数据 v27）` / `本机设备标识 DESKTOP-7F3A92·a1b2c3`

**禁用词（本行为清单原文，扫描豁免）**：`云端` `上云` `云端分析` `上传分析` `数据资产`；另禁止把遥测说成「改善体验」这类空话

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| 打开 | 焦点落在对话框容器（不落在任何控件上），`Tab` 进入第一项 |
| `Tab` / `Shift+Tab` | 在设置项间顺序移动（顺序与视觉顺序完全一致，遥测开关是第 1 站） |
| `Space`（焦点在 Switch） | 切换开关 |
| `←` / `→`（焦点在分段控件） | 在分段内移动并即时应用（RadioGroup 语义） |
| `Enter`（焦点在按钮） | 触发 |
| `Esc` | 关闭设置（热键录制态下 `Esc` 取消录制而非关闭） |
| `Ctrl+,` | 打开设置（Windows 约定） |

- Switch 用 `role="switch"` + `aria-checked`
- 分段控件用 `role="radiogroup"` + `role="radio"` + `aria-checked`
- 遥测开关状态变化需 `aria-live="polite"` 播报：`使用数据统计 已关闭`

## 7. 实现红线（本页最容易做错）

1. **遥测开关必须在第一行、一级可见、不折叠**。放进"高级设置"或"隐私"子页就等于没有这个开关（PRD §15.3 的 5–8 人可达性要求）。
2. **关闭遥测必须立即停止记录并清空缓冲**（AC-18），不是"下次启动生效"。清空的是 `events/events.jsonl` 与内存队列。
3. **关闭遥测不要二次确认弹窗**。弹窗会让人以为关不掉；直接生效 + 副文案变化 + 一行"已清空"反馈即可。
4. **热键冲突不得反复弹窗，也不得静默抢占**（AC-05）。本次会话只提示一次，写在设置页里等用户主动处理。
5. **主题读取失败兜底深色，且完全不提示**。这是一次性降级，弹提示只会制造困惑（D-06）。
6. **125% / 150% 缩放不得破版**。禁止写死 px 容器宽度；所有尺寸来自 Token，`1040×720` 是 CSS 像素，缩放由 Chromium 处理。
7. **口令只存在本机 `credential.json`**，不得上报、不得写进遥测、不得出现在诊断页里。
