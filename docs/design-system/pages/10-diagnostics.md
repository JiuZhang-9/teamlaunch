# 页面设计提示词 · 诊断页（V-10）

> 触发：打开失败 Toast 的「查看诊断」/ 更多菜单「诊断」/ 设置页「查看诊断」
> 数据源：`GET /api/v1/diagnostics`（Bearer + HMAC；**非管理员只能看到本机侧字段**）
> 定位：这是**全应用唯一允许出现 IP / 端口 / 错误码**的界面，也是 K-01（防火墙/公用网络）的主战场

---

## 1. 布局结构（具体尺寸）

居中对话框，宽 **600**（`--dialog-w-wide`），最大高 640。

```

   │ p 24                                                          │

   │ └──────────────────────────────────────────────────────────┘ │
```

| 元素 | 尺寸 | Token |
|---|---|---|
| 对话框 | w 600，最大 h 640，圆角 16 | `--dialog-w-wide` `--radius-xl` |
| 内边距 | 24 | `--space-6` |
| 结论块 | 圆角 8，p 12，h 48（两行 64）；bg 按语义（warn/danger） | `--radius-md` |
| 巡检块 | 圆角 8，1px `--border-subtle` | `--radius-md` |
| 巡检行 | 最小 h 44；键列固定 w 160，值列 flex | `--row-h` |
| 键 | 12 / 400，`--muted` | `--text-xs` |
| 值 | 13 / 400，**等宽**，`--fg` | `--font-mono` `--text-sm` |
| 状态图标 | 16（正常 `circle-check` / 异常 `triangle-alert` / 失败 `circle-x`） | `--icon-16` |
| 行分隔线 | 1px，左缩进 12，右 0 | `--border-subtle` |
| 底部按钮 | h 32，p-x 12 | `--control-h-md` |

**键列固定宽 160** 而非自适应：8 行里最长的键是「活动网络配置文件」（8 字 ≈ 96px @12px），固定宽能让所有值列左边缘对齐，扫描起来快一倍。

## 2. 组件组合（Spec §7 组件名）

```
DiagnosticsView（Dialog）
├─ DialogHeader   Text「诊断」 + Button(ghost)[X 16]
├─ Banner（条件，最多 1 个）
│  ├─ Icon 16 + 标题 13/510 + 说明 12
│  └─ Button(secondary)×≤2  切换引导 / 一键修复
├─ 巡检块
│  └─ 行 ×8  [Text 键][Text(mono) 值][Spacer][Icon 状态]
├─ 技术明细（默认折叠）
│  └─ MenuItem [ChevronRight 16] 原始巡检响应
└─ DialogFooter
   ├─ Button(secondary) [Copy 16] 复制诊断信息
   └─ Button(ghost)     [RefreshCw 16] 刷新
```

**结论块优先级**（同时命中多条时只显示最高的 1 条，其余降级为行内状态图标）：
1. `danger`：防火墙规则缺失
2. `warn`：活动网络配置文件 = 公用
3. `warn`：服务版本与客户端版本不一致
4. 无：不显示结论块

## 4. 真实中文文案

**标题**：`诊断`

**巡检行（键 / 值示例）**
| 键 | 值 |
|---|---|
| 服务监听地址 | `192.168.1.24:17890` |
| 实际端口 | `17890` |
| 防火墙入站规则 | `已创建` / `未创建` |
| 活动网络配置文件 | `专用` / `公用` |
| 服务版本 | `1.0.0` |
| 团队数据版本 | `v27` |
| 本机设备标识 | `DESKTOP-7F3A92·a1b2c3` |
| 最后成功同步 | `今天 09:12` / `从未成功同步` |

**结论块文案**
- S3 公用网络：`当前网络是「公用」，防火墙规则不会生效` / `把网络切换为「专用」后重试，或让管理员一键修复。` / `切换引导` `一键修复`
- S4 防火墙缺失：`入站防火墙规则不存在，其他电脑连不上这台` / `需要一次管理员权限才能创建规则。` / `一键修复`
- S5 版本不一致：`服务版本 1.0.0 与本机 0.9.4 不一致，建议更新后重试`

**无权限占位**：`需要管理员权限`

**请求失败**：`拿不到巡检信息` / `管理员电脑未开机或未连接网络。稍后会自动重试，你也可以手动刷新。` / `刷新`

**Toast**：`诊断信息已复制` / `防火墙规则已创建`

**复制格式（C-01 硬约束：路径一律 Windows 反斜杠）**
```
TeamLaunch 诊断信息
客户端版本 1.0.0
本机设备标识 DESKTOP-7F3A92·a1b2c3
服务监听地址 192.168.1.24:17890
防火墙入站规则 已创建
活动网络配置文件 公用
最后成功同步 今天 09:12
缓存路径 C:\Users\ ZhangSan\AppData\Roaming\TeamLaunch\cache\team-current.json
```

**禁用词**：同全局；诊断页禁止出现 `Fatal` `Exception` `Stack trace` 等未翻译的技术词（技术明细折叠区除外）

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| 打开 | 焦点落在对话框容器，`Tab` 进入结论块动作按钮（若有），否则进入「复制诊断信息」 |
| `Tab` | 结论块动作 → 技术明细折叠行 → 复制诊断信息 → 刷新 → 关闭 |
| `Enter` / `Space` | 激活 |
| `Ctrl+C` | 复制诊断信息（等价点按钮） |
| `F5` | 刷新巡检 |
| `Esc` | 关闭 |

- 巡检行用 `role="table"` / `role="row"` / `role="cell"`（值列是等宽文本，屏幕阅读器要能逐行读）
- 状态图标必须带 `aria-label`：`正常` / `需要注意` / `异常`
- 结论块 `aria-live="assertive"`（这是用户打开诊断页最想知道的事）

## 7. 实现红线（本页最容易做错）

1. **公用网络必须显式提示，不得静默失败**（AC-17）。K-01 是最高频现场故障：规则在公用配置文件下不生效，而用户完全不知道为什么连不上。
2. **结论块最多 1 个**。三条警告叠在一起等于没有警告；按 danger > warn > 版本不一致 的优先级取最高一条，其余降级为行内图标。
3. **路径一律 Windows 反斜杠**（C-01 裁定）。`D:\共享\2026 归档` 才能直接粘进资源管理器地址栏；正斜杠虽然多数场景能用，但会让非技术同事困惑。
4. **本机自连自身 IP 的自检不可信**（K-02）。回环不经过防火墙入站规则，所以"我自己连自己通"不代表别的电脑能连——真实验证必须由**第二台机器**完成，这条要在诊断页用 12px `--meta` 写清楚。
5. **员工查看时只给本机侧字段**。服务端字段行显示 `需要管理员权限`，不要留空白也不要显示 `***`。
6. **Loading 期间不要先渲染"异常"再翻正**。巡检未完成就显示红色结论块，会让用户以为确实坏了。
7. **诊断页是全应用唯一允许出现 IP / 端口的地方**。任何其他界面出现 `192.168.x.x:17890` 都算违规（员工可见界面尤其严格）。
