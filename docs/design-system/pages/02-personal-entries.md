# 页面设计提示词 · 我的入口页（V-02）

> 触发：PageTabs 第二项 / `Ctrl+2`｜数据源：本机 `config/personal.json`（**永不跨设备同步**）
> 角色：**本机可编辑**。与 V-01 的最大差异是工具栏右侧没有 SyncIndicator，取而代之是本机管理动作

## 1. 布局结构（具体尺寸）

与 V-01 共用壳层，差异只在 Toolbar 右段与底部没有 EditActionBar（本页是常态编辑，不需要"进入/退出编辑模式"这层仪式）。

```
┌──────────────────────────────────────────────────────────────────────┐
│ TitleBar                                                      h=40   │
├──────────────────────────────────────────────────────────────────────┤
│ Toolbar                                                       h=56   │
│ p-x 24 │ [PageTabs h=32]  [SearchInput w=280 h=32]  <flex>           │
│        │        [+ 添加 h=32] [导入 h=32] [导出 h=32] [more 32] [settings 32]  │
├──────────────────────────────────────────────────────────────────────┤
│ Content                                            992 × 580        │
│ padding: 20px 24px 24px                                              │
│  GroupHeader h=32  │  组间距 24（首组 0）                            │
│  CardGrid 6 × 152 + 5 × 16，card 152 × 132                           │
└──────────────────────────────────────────────────────────────────────┘
```

| 元素 | 尺寸 | 说明 |
|---|---|---|
| Toolbar 右段按钮组 | 高 32，间距 8 | 文字按钮与非文字按钮混排时，**文字按钮 p-x 12**，图标按钮 32×32 |
| 「添加」按钮 | 高 32，`Plus` 20 + 文字 `添加` | 本页唯一的 accent 实心按钮（**每屏 ≤2 处 accent**） |
| 卡片拖拽句柄 | `GripVertical` 16，右上角 hover 出现 | 本页卡片常驻可拖拽 |
| 卡片操作 | `Pencil` 16 / `Trash` 16，hover 出现 | 与拖拽句柄同处右上角，横向排 3 个 16px 图标，命中区各 24×24 |

**工具栏右段在窄窗口（704px）的降级**：`导入` / `导出` 收进 `EllipsisVertical` 菜单，只保留「添加」与「设置」。

## 4. 真实中文文案

**SearchInput placeholder**：`搜索我的入口`

**空状态**：`我的入口还没有内容` / `把常用的软件、文件夹和网页加进来，只有你能看到。` / `从本机添加软件` / `扫描开始菜单程序`

**更多菜单**：`从本机添加软件` `扫描开始菜单程序` `整理顺序` `导入 JSON` `导出 JSON`

**导入冲突对话框**
- 标题：`导入时遇到 3 个重复入口`
- 说明：`这些入口在本机已存在。选择处理方式后继续，不会覆盖你现有的内容。`
- 每行：`2026 年度归档` + RadioGroup：`另存副本`（默认）/ `覆盖现有` / `跳过`
- 底部：`全部另存副本` `全部跳过` / Button 主 `继续导入`

**导入失败**
- 标题：`这个文件无法导入`
- 说明：`D:\备份\我的入口-2026-09-29.json 不是有效的入口文件（第 14 行缺少 name 字段）。现有内容没有改动。`
- 动作：`复制错误信息` / `重新选择文件`

**导出成功 Toast**：`我的入口已导出到 D:\备份\我的入口-2026-09-29.json（共 14 项）`

**SourceTag**：`本机`（固定，副标签行右侧，12px，仅本页出现）

**禁用词（本行为清单原文，扫描豁免）**：同 V-01 清单；另禁止把个人入口说成「云端同步」「多设备可用」（MVP 明确不做）

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| `Ctrl+1` / `Ctrl+2` | 切到团队入口页 / 我的入口页 |
| `Ctrl+N` | 新建入口（等价「添加」） |
| `Ctrl+F` | 聚焦搜索框 |
| `Ctrl+O` | 导入 JSON |
| `Ctrl+S` | 导出 JSON |
| 卡片网格 `← → ↑ ↓` | 移动焦点（同 V-01） |
| `Alt+↑ / Alt+↓` | **移动当前卡片在组内的顺序**（拖拽的键盘等价物） |
| `Enter` | 打开 |
| `F2` | 重命名当前卡片（就地编辑，输入框替换标题） |
| `Delete` | 删除当前卡片（弹出确认，焦点回到被删卡片的后一张） |
| `Shift+F10` | 上下文菜单 |
| `Esc` | 取消就地编辑 / 焦点交回搜索框 |

- `Alt+↑/↓` 移动后必须通过 `aria-live="assertive"` 播报：`2026 年度归档 已上移到第 2 位`（否则键盘用户完全感知不到发生了什么）
- 删除确认对话框默认焦点在「取消」，不是「删除」

## 7. 实现红线（本页最容易做错）

1. **个人入口永不跨设备同步**。不得出现任何"同步中/已同步"字样，不得复用 SyncIndicator。
2. **导入冲突禁止静默覆盖**（AC-15）。默认必须是「另存副本」；批量操作按钮要写清楚是"全部另存副本"还是"全部跳过"，不能只写"确定"。
3. **导入失败不得改动现有数据**（AC-14）。先解析校验完整份文件，通过后再写盘；写盘用原子写（临时文件 + rename）。
4. **`Delete` 删除必须确认**，且确认对话框默认焦点在「取消」。Delete 在只读的团队页完全不生效（V-01 无此键位）——两个页面共用 EntryCard 组件，键位由页面注入。
5. **卡片右上角三个 16px 图标（手柄/编辑/删除）命中区必须是 24×24**，不是 16×16。视觉 16px、命中 24px 是两件事，别用同一个数。
6. **副本命名规则固定**：`2026 年度归档（副本）`；已存在则 `（副本 2）`，以此类推。
