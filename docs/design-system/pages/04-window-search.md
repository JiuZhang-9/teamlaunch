# 页面设计提示词 · 窗口内搜索结果（V-04）

> 触发：工具栏 `SearchInput` 输入非空｜数据源：**本机内存索引**（与 V-03 同一份索引，同一套排序）
> 作用域：只搜**当前 Tab**。在团队页搜团队入口，在我的入口页搜个人入口——不做跨 Tab 混合搜索

## 2. 组件组合（Spec §7 组件名）

```
MainWindowShell
├─ TitleBar
├─ Toolbar
│  ├─ PageTabs
│  ├─ SearchInput      ← 输入态：右侧出现 [X 16] 清空按钮
│  └─ …（与 V-01/V-02 右侧一致）
└─ Content
   ├─ 计数行            Text「找到 7 个入口 · 团队入口」
   └─ SearchResultsState
      ├─ ResultRow ×N   [Icon 24][标题 + 副标签][Spacer][TypeTag]
      └─ EmptyBlock（0 结果时）
```

- 结果**不分组**，按相关度平铺（分组信息体现在副标签或 TypeTag 旁的分组名）
- 每条结果依然必须同时有类型图标与类型文字（AC-03）
- **结果行不提供拖拽/编辑**——搜索态是只读视图，避免"在搜索结果里拖拽排序"这种无解交互

## 3. 需要实现的全部状态

| # | 状态 | 触发 | 呈现 |
|---|---|---|---|
| S1 | Idle（未输入） | 搜索框为空 | 显示原卡片网格（本视图不挂载） |
| S2 | Typing | 输入中，防抖 120ms 未完成 | 保留上一次结果；计数行显示 `--meta` 的 `搜索中…` |
| S3 | Results | 匹配 ≥1 | 列表 + 计数行 `找到 7 个入口 · 团队入口` |
| S4 | Empty | 匹配 0 | `EmptyBlock`（内容区垂直居中，最大宽 360）：`Search` 24 + `没有找到「报价」相关的入口` + `换个词试试，也可以在我的入口里添加` |
| S5 | Row Hover | 鼠标悬停 | `--row-bg-hover`，不做位移/缩放 |
| S6 | Row Selected | `↑↓` 键盘移动 | `--row-bg-selected` + 2px 左竖条 |
| S7 | Row Loading | 点击后正在打开 | 行右侧 TypeTag 换成 `Spinner` 16，**行仍可继续点击**（不阻塞） |
| S8 | Row Failed | 打开失败 | 行右侧出现 `TriangleAlert` 16 + 副标签换 `没能打开，点击查看原因` |
| S9 | 清空 | 点击 `[X]` 或 `Esc` | 回到卡片网格，滚动位置恢复到进入搜索前 |
| S10 | 切 Tab | 搜索中切到另一个 Tab | **清空搜索词并回到卡片网格**（因为作用域是单 Tab，保留词会造成"7 个结果突然变 2 个"的困惑） |
| S11 | 软更新到达 | 轮询更新 | 如处于搜索态，**保留搜索词与选中项**，只更新数据源；确有变化时计数行右侧追加一行 11px `--accent-text`：`结果已更新` |

## 5. 键盘操作路径

| 按键 | 行为 |
|---|---|
| `Ctrl+F` | 聚焦搜索框并全选 |
| `↑` / `↓` | 在结果行间移动（**不循环**，到顶/到底停住） |
| `Enter` | 打开选中行；**面板/网格不关闭**，搜索词保留 |
| `Alt+1` … `Alt+9` | 直接打开第 n 行（与 V-03 保持一致） |
| `Esc` | 第一次：清空搜索框并回到卡片网格；搜索框已空：焦点交回卡片网格 |
| `Tab` | 从搜索框 → 结果行首项（列表只占 1 个 tab stop，内部用 `↑↓`） |
| `Shift+F10` | 打开行的上下文菜单（打开 / 复制路径或链接 / 反馈给管理员） |

- 结果列表用 `role="listbox"`，行用 `role="option"` + `aria-selected`
- 计数行挂 `aria-live="polite"`：`找到 7 个入口`

## 7. 实现红线（本页最容易做错）

1. **搜索只作用于当前 Tab**。团队页与个人页是两个数据源；跨 Tab 混合会让用户搞不清搜到的东西属于谁。切 Tab 必须清空搜索词。
2. **防抖 120ms 内不要清空旧结果**。清空再渲染会造成列表闪烁，在 200 条数据下尤其明显。
3. **打开用 `Enter` 后不要关闭搜索态**。用户经常要连开好几个入口；关掉搜索态等于强迫他重新输一遍。
4. **`loader-circle` 旋转必须受 `prefers-reduced-motion` 约束**（`data-motion="loop"`）。reduced-motion 下改成静态 `Clock` 16，不是"转得慢一点"。
5. **分隔线左缩进 60px** 对齐文字起点。贴边分隔线会让列表看起来像廉价表格。
6. **软更新到达时保留搜索词与选中项**（AC-08）。更新后列表内容变了但选中项被重置，是最常见也最招骂的回归。
7. **本视图同样 100% 本地**，不得发起网络请求。
