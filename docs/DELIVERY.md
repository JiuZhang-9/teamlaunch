## 2. 未签名包的 SmartScreen 告警与手动放行（必读）

未签名的安装包在 Windows 10/11 上会被 SmartScreen 拦截，表现为蓝/黄色窗口：
「Windows 已保护你的电脑」→ "Microsoft Defender SmartScreen 阻止了未识别的应用启动。运行此应用可能会导致你的电脑受到损害。"

**手动放行步骤（转发给每一位试点用户）：**

1. 在 SmartScreen 窗口点击 **"更多信息"**（不是"不要运行"）。
2. 出现 **"仍要运行"** 按钮后点击它。
3. 若安装包被浏览器下载拦截：在浏览器下载列表里右键该文件 → "保留" / "保留此文件"，再运行。

**说明**：这不是病毒告警，只是 Windows 对未签名程序的默认提示。确认安装包来自团队内部可信渠道后再放行。正式推广前会补上代码签名（D-01），届时该提示消失。

## 3. 安装步骤（管理员机必读）

安装分两种角色，**防火墙规则只在管理员机需要**，且必须在安装时完成：

1. **以管理员权限运行安装器**（右键安装包 → "以管理员身份运行"）。
   这一步是关键：Windows 防火墙入站规则只能在提权阶段创建。普通双击安装不会创建规则，后续员工端将全部连不上。
2. 安装完成后启动应用 → 设置 → 启用「管理员角色」并**设置管理员口令**（无默认口令）。
3. 建议同时开启「开机自启」与「托盘常驻」，否则应用关闭即等于同步服务停止，员工端会进入离线状态。

**员工机**：正常安装即可，**不需要任何防火墙配置、不需要知道管理员 IP、不需要修改网络设置**。

## 4. 安装后自检（管理员机）

安装并启动后，打开应用内「诊断」页，确认以下四项全绿：

| 巡检项 | 期望 |
|---|---|
| 服务正在监听 | 通过 |
| 端口在 17890–17899 内 | 通过（漂移可接受，会由发现广播告知员工端） |
| 防火墙规则（TCP / UDP 两条） | 存在且启用 |
| 活动网络配置文件 | 专用（Private）或域（Domain） |

**若活动网络配置文件是"公用（Public）"，防火墙规则不生效，这是最高频的现场故障（K-01）。** 处理方式：设置 → 网络和 Internet → 属性 → 改为"专用"。

## 5. 重要：真实验证必须用第二台机器

**不要只用管理员机自测就判定同步可用。** 本机访问自己的局域网 IP 走的是回环，不经过防火墙入站规则，会给出假阳性（K-02）。
正确的验证方式是：在第二台机器上装好客户端，看它能否在 3 秒内拿到团队入口并在顶部显示"已同步"。

## 6. 自用两周验证的重点（用户即管理员）

建议按 `docs/SPEC.md` §12 的端到端步骤逐条走一遍，其中最容易暴露问题的四处：

1. 员工机能否自动发现服务（管理员 IP 变了以后是否仍能连上）。
2. 把管理员机网络切成"公用"后重启员工端，诊断页是否给出明确提示。
3. 管理员机关闭应用后，员工端是否降级到缓存且卡片仍可点击。
4. 在员工机上用 `curl` 直接 `PUT /api/v1/config`（不带签名），是否返回 401 且团队配置未被改动。

遇到问题时第一反应打开「诊断」页 —— 它首行直接给出最可能的根因（`topIssue`），依次为：服务未监听 / 公用网络配置文件 / 防火墙规则缺失 / 端口漂移 / 数据完整性异常 / 需第二台机器验证。

## 7. 数据位置与重置

所有数据位于 `%APPDATA%\TeamLaunch\`：

```
settings.json          本机设置
identity.json          匿名设备标识
credential.json        仅管理员：口令派生参数（删除它即可重设口令）
cache\team-current.json  团队配置缓存
config\personal.json     个人入口（本机，不上网）
revisions\              发布历史与快照（滚动 20 条）
assets\                 图标缓存
outbox\feedback.jsonl   待发送反馈
events\                 本地遥测缓冲（隐私说明确认后才创建）
logs\main.log
```

**口令忘了怎么办**：删除 `credential.json` 后重启客户端，回到首次运行引导重设口令。这意味着对管理员机器有本地文件访问权的人等同于有管理权 —— 这是本方案明示的安全边界，不是缺陷。

## 8. 隐私开关

遥测默认开启，但：

- **首次启动会先展示隐私说明，未确认前不会记录也不会上传任何数据**（零记录，磁盘上不存在遥测文件）。
- 设置 → 关闭遥测后，立即停止本地记录、清空未发送缓冲、不再发起任何请求。
- 遥测不接入任何第三方互联网服务，只上报到管理员客户端；不采集 IP、原始搜索词、完整路径、个人入口内容、硬件序列号。
