最近打开 · 扩展方案原型

现在「最近打开」只显示手动加过的入口。这个原型演示扩展后的口径：通过 TeamLaunch 打开过的 本机程序 / 文件夹 / 网页 / 整条连锁 也会进入最近打开， 但不会自动加入入口清单。开关默认开启，设置与「最近打开」标题行两处同步。

快捷面板 · 空查询时显示 收藏 → 最近打开
悬停看图块来源 · 点图块试「移到最前」

设置 · 通用

新开关放在现有设置面板里，与「开机自启 / 托盘 / 公告提醒」同一层级。
最近打开记录
开启后，通过快捷搜索直接打开的本机程序、文件夹、网页与整条连锁也会进入「最近打开」； 不会加入入口清单，仅本机保存、不同步。

图块来源

真实界面里图块只显示名称；来源放在悬停提示与副标题里，避免同一行里再挤标签。
把鼠标移到左侧图块上
会显示「入口 / 未加入入口」与程序、文件夹、网页、连锁的具体来源。

口径

  • 只记通过 TeamLaunch 打开成功的对象；不监听资源管理器或其它软件。
  • 不自动加入入口，不写 personal.json，不跨机同步；最近记录仍只存本机。
  • 网页标题与添加入口同一逻辑：打开未加入入口的网页时取一次 <title>，失败回落域名。
  • 连锁是一条记录 = 一整条连锁，不拆步骤；点击重跑整条连锁。
  • 关闭开关：未加入入口的记录（含连锁）立即隐藏并停止新增；已记录的保留，重新开启后恢复。

说明：已收藏的连锁仍在「收藏」行；按现有去重规则，它不会在「最近打开」里重复出现。 原型里的图块点击只弹提示，不会启动真实程序。
